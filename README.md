# Book-Bestsellers-Analysis

This project analyzes New York Times Bestselling books using **Python**, **Pandas**, and **Seaborn**.  

As someone who loves reading, I wanted my **first data analysis project** to combine my personal interests with practical skills. Exploring the patterns behind bestselling books — from top authors to genre trends, user ratings, and yearly performance — felt like a natural way to practice **data cleaning, exploration, and visualization** while working with a real-world dataset.

This project is designed to showcase skills relevant for **data analysis and data science roles**, while also telling a story about my personal interests and how I approach projects with curiosity and passion.

---

## Dataset

The dataset used is `bestsellers_with_categories.csv`, which contains 550 books with the following columns:

- **Name** – Book title  
- **Author** – Name of the author  
- **User Rating** – Average user rating  
- **Reviews** – Number of user reviews  
- **Price** – Price of the book  
- **Year** – Year the book was on the bestseller list  
- **Genre** – Fiction or Non Fiction  

---

## Features & Analysis

1. **Top Authors** – Displays the top 10 authors by number of bestsellers.  
2. **Top Authors by Genre** – Shows the leading authors within Fiction and Non Fiction genres.  
3. **Genre Distribution** – Counts the number of bestsellers in each genre.  
4. **Yearly Trends** – Shows the number of bestsellers per year (2009–2019).  
5. **Top Books by Reviews** – Lists books with the most user reviews.  
6. **User Rating vs Reviews** – Scatterplot showing the relationship between rating and reviews by genre.  
7. **Average Price by Genre** – Compares the average price of books in each genre.
