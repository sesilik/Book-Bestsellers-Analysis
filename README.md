# Book Bestsellers Analysis 📚

## Project Overview
I’ve always loved reading, so for my first data analysis project, I chose to explore a dataset of book bestsellers. This project demonstrates my ability to clean, explore, and visualize data using Python, pandas, Matplotlib, and Seaborn.

The analysis focuses on:
- Identifying top authors and genres
- Tracking bestseller trends over the years
- Examining book ratings and reviews
- Visualizing key insights with plots

---

## Dataset
The dataset used is `bestsellers_with_categories.csv`, which contains 550 bestseller books along with the following columns:
- `Name` – book title
- `Author` – author name
- `User Rating` – average rating out of 5
- `Reviews` – number of reviews
- `Price` – book price
- `Year` – publication year
- `Genre` – Fiction or Non Fiction
